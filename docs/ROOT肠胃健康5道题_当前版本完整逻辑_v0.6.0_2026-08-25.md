# ROOT 肠胃健康 5 道题：当前版本完整逻辑

> 文档版本：v0.6.0 提审候选版
> 导出日期：2026-08-25
> 逻辑来源：当前小程序代码与自动化测试
> 当前问卷版本：`ROOT_GUT_5Q / questionnaireVersion = 2`
> 当前定义 ID：`local-gut-5q-v2`

## 1. 产品定位与使用边界

“肠道健康 5 道题自测”用于帮助用户记录近期排便频率、便便形态、肠胃感受、可能诱因及饮食饮水习惯，并生成日常健康管理参考。

- 预计用时：约 2 分钟。
- 共 5 道必答题。
- 结果不构成疾病诊断、治疗、用药建议或干预疗效判断。
- 当前结果为规则判断，不是医学评分，也不展示数值分数。
- 问卷答案、结果和历史记录保存在用户当前设备的小程序本地存储中，不同步至服务端。
- 服务端仅记录健康数据处理授权状态及其审计信息。

## 2. 入口与页面流转

### 2.1 固定入口路径

```text
subpkg/health/pages/assessment/index?assessmentType=GUT_REGULARITY
```

代码内部使用带前导斜杠的页面路径：

```text
/subpkg/health/pages/assessment/index?assessmentType=GUT_REGULARITY
```

### 2.2 首次进入

用户从固定路径进入且 URL 中没有 `assessmentId` 时：

1. 先进入“ROOT 陪伴计划”问卷前置页；
2. 用户点击“开始肠道自测”；
3. 本地写入一次性继续凭证 `ROOT_GUT_INTRO_CONTINUE_V1`；
4. 凭证有效期为 10 分钟；
5. 返回健康评测页并继续登录、健康数据授权和创建问卷流程；
6. 问卷实例创建成功后，继续凭证被清除。

### 2.3 继续未完成问卷

当 URL 中带有有效 `assessmentId` 时，直接恢复对应问卷，不重复展示前置页。

同一用户范围、同一问卷 ID、同一问卷版本同一时间只保留一个进行中的实例；再次进入时优先恢复该实例。

### 2.4 登录与健康数据授权

进入问卷前依次执行：

1. 检查登录状态；
2. 未登录时保存原始访问意图，跳转登录页；
3. 登录后检查服务端健康数据处理授权状态；
4. 未授权时进入健康数据授权页；
5. 授权生效后创建或恢复本地问卷。

授权记录包含授权状态、政策版本和来源等服务端审计信息，但不上传本次问卷答案与结果。

### 2.5 Launching 页面规则

健康问卷固定入口、前置页、问卷页等深链路属于 Launching 绕过路径。正常从这些入口进入时，不应在页面跳转过程中闪现 Launching 页面。

## 4. 当前 5 道题完整内容

### Q1：排便频率

- 类型：单选
- 必答：是
- 题目：过去 7 天，你的排便频率大概是？
- 辅助说明：选一个最接近的情况

| 选项 | 文案 |
|---|---|
| A | 每天 1–2 次 |
| B | 每 2–3 天 1 次 |
| C | 每周 2 次及以下 |
| D | 每天 3 次及以上且偏稀 |
| E | 频率波动大（有时偏少、有时偏多） |

### Q2：便便形态

- 类型：单选
- 必答：是
- 题目：过去 7 天，最常见的便便形态是？
- 辅助说明：参考下图，选择最常见的形态
- 配图：`/subpkg/health/assets/bristol-stool-scale.jpg`

| A | 第 1–2 型：小硬球，或表面凹凸的香肠状 |
| B | 第 3–4 型：像香肠或蛇，表面有裂痕或顺滑柔软 |
| C | 第 5 型：断边平滑的柔软块状，容易通过 |
| D | 第 6–7 型：蓬松糊状，或水样、没有固体块 |

## 5. 作答与保存规则

### 5.1 必答与题型

- 5 道题全部必答。
- Q1、Q2 为单选。
- Q3、Q4、Q5 为多选。
- 当前 v2 没有条件显示题，5 道题始终依次出现。

### 5.2 排他选项

多选题中：

- 选择排他选项时，已选普通选项会被清除；
- 选择普通选项时，已选排他选项会被清除；
- Q3 的 A、Q4 的 A/F、Q5 的 A 按此规则处理。

### 5.3 草稿与继续

- 点击“下一步”前先将当前答案保存至本机；
- 保存失败时停留当前题并提示重试，不进入下一题；
- 页面进入后台或离开时，如存在未保存修改，则尝试保存草稿；
- 已完成问卷不可继续改写；重复提交完成操作时返回原有结果。

### 5.4 初测、回测与历史

- 首次完成的问卷视为初测；
- 已完成后再次开始会创建新的独立实例，并标记为回测；
- 每次完成结果单独保留在本机历史中，不覆盖上一轮。

## 6. 当前结果分类逻辑

### 6.1 中间状态变量

系统先根据答案生成四个布尔状态：

```text
constipation（偏慢/偏干硬） =
  Q1 为 B 或 C
  或 Q2 为 A
  或 Q3 选择 G

loose（偏快/偏稀） =
  Q1 为 D
  或 Q2 为 D
  或 Q3 选择 H

alternating（波动） =
  Q1 为 E
  或 Q2 为 E
  或 constipation 与 loose 同时成立

sensitive（敏感） =
  Q3 选择 B、C、D、E、F、I 中任一项
  或 Q4 选择 B、C、D、E 中任一项
```

### 6.2 分类优先级

按以下顺序命中第一个结果：

1. `alternating = true` → `ALTERNATING`
2. `constipation = true` 且 `loose = false` → `CONSTIPATION`
3. `loose = true` 且 `constipation = false` → `LOOSE`
4. `sensitive = true` → `SENSITIVE`
5. 以上均未命中 → `HEALTHY`

### 6.3 特别说明

- Q2 选择 C（布里斯托第 5 型）不会单独判定为偏稀；在其他条件均未命中时，结果仍可能为 `HEALTHY`。
- Q5 不影响结果分类，只用于补充个性化行动建议。
- 同时出现偏慢与偏快信号时，优先判为 `ALTERNATING`。
- “敏感”信号的优先级低于“波动、偏慢、偏快”。
- 当前没有总分、维度分或医学风险分数。

## 7. 五类结果完整文案

### 7.1 CONSTIPATION：肠道的节奏慢了些

**结果说明**

你的近期记录中出现了排便间隔较长、便便偏干硬或排便费力中的一种或多种情况。可以从饮食、饮水和日常活动三个容易执行的方向开始观察。

**基础行动建议**

1. 逐步增加蔬菜、全谷物和豆类，不要一次加太多。
2. 白天少量多次饮水，留意自己的实际耐受。
3. 饭后安排 5–10 分钟轻松走动。

### 7.2 LOOSE：肠道的节奏快了些

**结果说明**

你的近期记录中出现了便便偏稀、排便次数偏多或便急中的一种或多种情况。先减少刺激、保持规律并观察变化。

**基础行动建议**

1. 近期减少辛辣、油腻和生冷食物。
2. 注意补充水分；如有明显不适，请及时咨询专业人士。
3. 尽量保持固定的进餐和休息时间。

### 7.3 ALTERNATING：肠道的节奏有点乱

**结果说明**

你的近期记录显示排便频率或便便形态不太稳定，可能在不同日期出现偏少、偏多、偏硬或偏稀等变化。先找出变化规律，再从一个小习惯开始调整。

**基础行动建议**

1. 记录几天排便时间、形态和饮食，寻找变化规律。
2. 尽量固定起床和进餐时间。
3. 每次只调整一个习惯，连续观察后再判断。

### 7.4 SENSITIVE：肠道有些敏感

**结果说明**

你的近期记录中出现了腹胀、腹痛、反酸、餐后不适等感受，或你观察到压力、饮食和环境变化与肠胃不适同时出现。温和观察，比一次改变很多更重要。

**基础行动建议**

1. 吃饭时放慢速度，留意餐后感受。
2. 记录可能引起不适的食物或情境。
3. 减少刺激性饮食，并保持规律作息。

### 7.5 HEALTHY：肠道节奏挺稳，值得继续保持

**结果说明**

你的近期记录显示排便频率和便便形态较为稳定，也没有记录到明显的肠胃不适。日常养护的重点，是让容易坚持的好习惯继续发生。

**基础行动建议**

1. 继续保持规律饮食和充足饮水。
2. 保持相对固定的起床和进餐时间。
3. 每周记录一次排便形态与身体感受。

## 8. “优先行动”生成规则

### 8.1 必出项目

所有结果的第一项固定为：

```text
推荐服用膳食纤维
```

该项只出现一次。

### 8.2 生成顺序

完整“优先行动”列表按以下顺序组成：

1. 固定必出项目“推荐服用膳食纤维”；
2. 当前结果类型对应的 3 条基础行动建议；
3. 最多 2 条个性化补充建议。

因此最终一般展示 4–6 条行动建议。

### 8.3 个性化建议规则

系统按下表顺序判断，最多取前 2 条：

| 条件 | 补充建议 |
|---|---|
| Q4 选择 B | 压力明显时，给自己留几分钟散步或放松呼吸。 |
| Q4 选择 C，或 Q5 选择 G | 进餐时间波动较大时，先固定一天中的一餐。 |
| Q4 选择 E | 季节变化或受凉时，注意腹部保暖。 |
| Q5 选择 E | 可以把饮水拆成多次完成，避免一次喝很多。 |
| Q5 选择 D 或 F | 减少加工食品或含糖饮料，并观察身体感受。 |
| Q3 选择 C | 如腹痛持续、加重或伴随异常信号，请及时咨询专业人士。 |

## 10. 当前版本没有安全题或中止分支

这是理解当前版本时最容易混淆的部分：

- 当前 v2 的第 5 题是“饮食与饮水习惯”，不是安全筛查题；
- 当前 v2 不根据答案触发安全中止；
- 当前 v2 完成后状态均为 `COMPLETED`，`safetyState = NONE`；
- 便血、黑便、明显体重下降、夜间痛醒等异常信号目前只出现在结果页风险提示中；
- 旧版 v1 曾存在安全题及条件流程，代码仅用于读取历史 v1 草稿或结果，不用于当前新建问卷。

因此，不能把当前版本描述为“完成 5 题后先经过安全题拦截，再决定是否展示结果”。

## 12. 本机存储、保留期与用户隔离

### 12.1 存储键与版本

```text
storageKey = ROOT_LOCAL_HEALTH_ASSESSMENTS_V060
storageVersion = 1
retentionDays = 180
```

### 12.2 保存内容

本机存储保存：

- 问卷实例及状态；
- 当前题目位置；
- 草稿答案；
- 完成答案；
- 结果类型与结果文案；
- 初测/回测标记；
- 创建、更新和完成时间。

结果页接收的公开对象会移除答案和完整问卷定义，但底层本机历史仍保留答案，用于恢复和历史逻辑。

### 12.3 用户范围

- 未登录时使用当前安装实例范围；
- 登录后绑定当前用户范围；
- 同一用户在同一设备可恢复自己的历史；
- 不同登录用户之间隔离；
- 退出登录后不展示原会员历史；
- 不支持跨设备同步与恢复。

### 12.4 清理规则

- 以 `updatedAt` 为主要时间依据清理超过 180 天的记录；
- 小程序启动及读取健康数据时执行清理；
- 用户清除小程序本地数据后，问卷草稿、答案、结果和历史会被删除。

## 13. 历史记录与回测对比

### 13.1 历史列表

- 历史支持“全部 / 初始评测 / 肠道自测”筛选；
- 默认按最近完成时间倒序；
- 每次完成的 v2 问卷作为独立记录保留；
- 当前肠道 v2 正常只产生 `COMPLETED` 记录。

### 13.2 对比条件

两次记录要进行维度对比，必须满足：

1. 是两个不同的已完成实例；
2. `questionnaireId` 相同；
3. `questionnaireVersion` 相同；
4. 存在共同的数值维度。

### 13.3 当前肠道问卷的实际对比能力

当前肠道 v2 的 `dimensions` 为空，因此没有数值维度可比较。

- 用户可以选择两次 v2 记录；
- 页面可并列显示两次结果标题，并分别进入结果详情；
- 系统会标记为 `NO_SHARED_DIMENSIONS`；
- 不展示数值升降、趋势曲线或改善幅度；
- v1 与 v2 因版本不同不能直接对比。

当前“回测对比”更准确的定义是“保留多次历史并并列查看结果”，而不是量化趋势分析。

- 分享路径只保留 `assessmentType=GUT_REGULARITY`；
- 不分享 `assessmentId`、答案或结果；
- 前置活动页分享时也指向固定问卷入口；
- 结果页、历史页、对比页属于敏感健康页面，分享时回落到小程序首页，不携带用户健康数据。

## 15. 埋点与数据边界

当前评测运行在 `LOCAL_DEVICE` 模式。为避免把本机健康评测行为或结果发送到服务端，以下评测相关事件被抑制：

- `assessment_start`
- `assessment_complete`
- `assessment_compare_view`
- `campaign_assessment_start`
- `assessment_result_view`
- `trial_pack_action`

答案字段不在通用埋点允许列表中。活动页面浏览或分享可能产生普通页面级埋点，但不包含问卷答案与结果。

## 18. 一句话流程总结

```text
固定入口
→ 前置页
→ 登录

→ 完成 5 道必答题

→ 固定输出“推荐服用膳食纤维”及基础/个性化建议

```

## 19. 当前版本关键结论

1. 当前正式新建问卷是 v2，不是历史 v1。
2. 第 5 题是饮食饮水习惯题，不是安全题。
3. 当前没有安全中止分支，异常信号通过结果页风险提示表达。
4. 当前没有分数，结果由固定规则分类产生。
5. Q5 不决定结果类型，只影响个性化建议。
6. “推荐服用膳食纤维”为所有结果第一条必出行动。
7. 完成当前 v2 即展示体验装领取入口，最终资格和库存由会员商城决定。
8. 答案、结果和历史仅保存于本机 180 天，不跨设备同步。
9. 肠道 v2 没有数值维度，因此回测对比不展示量化趋势。
10. 分享入口不携带实例、答案或结果，敏感结果页面不直接分享健康内容。
