## MySQL 与 CI

- 用户标签测试改用 SCHEMA_SNAPSHOT_MYSQL_* 配置；仅接受回环地址及空的专用 marker 实例，保留随机测试库/账号和合成外部 Adapter。新增 CI 专项明确要求 1 PASS / 0 FAIL / 0 SKIP。
- 实测发现旧 068 测试错误加载全部迁移，却断言停在 068。现固定该历史范围；完整 schema 验证仍包含 069–075。清理仅针对本次 CREATE 成功的库，拒绝后不执行 DROP。
- 固定 MySQL 8.0.43 的真实 schema 验证通过；generation 2/2、Activity P0 2/2、历史迁移 2/2、标签 1/1，零跳过。涵盖原来本地全量检查跳过的 5 个真实数据库场景。
- 独立审查发现的清理问题已修复；7 个纯 mock 拒绝/部分创建/清理异常场景通过，无未解决 P1/P2。
- 本地完整门禁 7/7：1,102 PASS，5 个默认 MySQL SKIP 已由上述独立专项补验。CI 额外保存完整验证日志与 TAP 摘要。
