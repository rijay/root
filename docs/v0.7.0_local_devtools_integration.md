# myRoot 0.7.0 微信开发者工具本地联调

## 边界

- 仅 `envVersion=develop` 且运行平台精确为 `devtools` 时，请求切到 `http://127.0.0.1:8787`。
- 体验版、正式版、真机开发版继续使用 `cloudContainer`，不会访问本机地址。
- 本地后端只监听 `127.0.0.1:8787`，并使用独立 SQLite 文件 `backend/data/myroot-v070-devtools.sqlite`，不会向局域网开放，也不会读写 CloudBase 或生产 MySQL；配置本机有赞只读令牌后，仅按需读取会员摘要和商品快照，不执行写操作。
- 启动脚本会幂等写入带 `MYROOT_V070_LOCAL_DEVTOOLS` 标记的开发态评测定义，题目复用当前小程序中的健康起点 12 题和肠道健康 5 题；不会覆盖其他定义或本地用户记录。
- 开发态种子只有在显式开关、`NODE_ENV=development`、`127.0.0.1`、专用 SQLite 文件和本地 OpenID 登录同时成立时才启用，任一条件不符即拒绝启动。
- 本地联调不替代已知测试会员的 UnionID 端到端验收、云端跨设备保存、生产凭据配置和真机验收。

## 启动

```bash
npm run dev:miniprogram --prefix backend
```

微信开发者工具私有配置 `miniprogram/project.private.config.json` 需要设置：

```json
{
  "setting": {
    "urlCheck": false
  }
}
```

该文件已被 Git 忽略且不会上传。仓库中的 `project.config.json` 仍保持 `urlCheck=true`。

停止服务时在运行该命令的终端按 `Ctrl-C`；服务会先停止接收请求，再关闭 SQLite。

## 本地测试身份

本地启动命令仅在非受保护运行时开放显式 OpenID 登录。可在开发者工具 Console 执行：

```js
wx.request({
  url: "http://127.0.0.1:8787/api/v1/auth/login",
  method: "POST",
  data: { openid: "myroot-local-devtools", appCode: "MYROOT" },
  success({ data }) {
    wx.setStorageSync("ROOT_TOKEN", data.data.token);
  },
});
```

此身份只存在于本地 SQLite；不得把本地 token、OpenID 或 SQLite 文件用于体验版和正式版。

## 健康建议

两项评测都完成后，`POST /api/v1/health/advice/generate` 会按正式 Interface 生成并保存建议快照。运行时只在后端读取仓库内的已审核建议池，并用 `INITIAL` 与 `GUT_REGULARITY` 两个结果代码进行本地匹配；不会访问模型服务，也不会读取模型钥匙串。建议池缺失、88 个组件未全部审核或内容校验不通过时，保存经审核的 `REVIEWED_FALLBACK`；安全停止分支始终使用 `REVIEWED_SAFETY`。

当前仓库已有离线起草的建议池，但仍为 `DRAFT`，尚未完成人工审核，也未接入运行时。可用下列命令验收两项评测完成后的经审核兜底链路；该命令只接受 `REVIEWED_FALLBACK`，不能作为建议池已审核或已启用的证据：

```bash
npm run verify:health-advice:fallback --prefix backend
```

建议池源文件为 `backend/data/health-advice-pool.v1.json`。它包含 36 条健康起点行动、30 条肠道行动、6 条回测提示、11 条状态摘要和 5 条安全提醒，共 88 个审核组件；与 5 条锁定的膳食纤维首条组合后，覆盖 30 个评测状态和 1080 种行动组合。草稿组件全部标记为 `PENDING_REVIEW`，不能被运行时读取。只有 88 个组件逐项完成内容与安全审核、填写审核人和审核时间、整体标记为 `APPROVED` 并进入候选工件后，才允许进行运行时接入。

当前内容池由 Codex 在仓库内离线起草，不需要 CloudBase、hy3 或本地模型钥匙串。历史 CloudBase 生成器和钥匙串脚本不属于本方案的执行路径；生产、体验版和真机不得配置健康建议模型凭据，也不得发起实时模型请求。

## Root 会员中心只读联调

本地启动脚本只从 macOS 钥匙串读取短期有赞 `access_token`，不读取 `client_secret`，也不把令牌写入仓库、`.env`、SQLite、命令参数或日志。令牌不可用、接口超时、网关返回异常或身份映射不唯一时，订单和优惠券摘要失败关闭并继续提供会员中心跳转；商品接口回退到仓库中的官方商品基础信息。

钥匙串条目：

- service：`com.myroot.v070.youzan-access-token`
- account：`youzan-root-store`

本地适配层执行以下最小化读取：

- 使用经 myRoot 验证的微信 UnionID 查询唯一 `yz_open_id`；零条或多条映射均不继续。
- 订单只返回总数和待处理数量，不缓存或返回订单号、金额、商品明细、收货人、手机号和地址。
- 优惠券只返回有效数量和可准确计算时的七天内到期数量，不缓存或返回券码、核销码和活动明细。
- 商品只覆盖两件官方商品的价格、图片、SKU 名称和库存状态；标题、文案和跨小程序跳转路径仍以仓库白名单为准。
- 会员摘要在进程内缓存 60 秒，商品快照缓存 5 分钟；缓存键使用 UnionID 摘要，不保存 UnionID 原文。

验证两件官方商品的实时字段形态：

```bash
npm run verify:youzan:local --prefix backend
```

该命令只输出命中商品数、价格字段数、SKU 数和同步时间是否存在，不输出令牌或商品原始载荷。订单和优惠券端到端验收还需要一个已明确授权的测试会员 UnionID；不得随机查询其他会员。

2026-08-26 使用项目负责人明确授权的单个测试会员手机号完成一次本地只读校准：通过有赞官方手机号查询接口唯一解析到有赞客户标识，订单与优惠券摘要接口均成功返回。校准过程未持久化手机号、有赞客户标识或原始响应，结束后已删除临时脚本和 IPv4/IPv6 白名单。该结果只证明有赞侧客户解析及下游摘要链路可用，不能替代 myRoot 经可信服务端取得 UnionID 后的完整身份映射验收。

有赞应用 IP 白名单只允许加入当前开发机的临时 IPv4/IPv6，说明中必须标注“完成后移除”。联调结束后删除两条临时记录。正式环境需配置独立出口 IP、轮换已暴露的旧 `client_secret`，并使用正式密钥管理；本机临时令牌和 IP 白名单都不是发布凭据。
