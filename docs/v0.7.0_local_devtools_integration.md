# myRoot 0.7.0 微信开发者工具本地联调

## 边界

- 仅 `envVersion=develop` 且运行平台精确为 `devtools` 时，请求切到 `http://127.0.0.1:8787`。
- 体验版、正式版、真机开发版继续使用 `cloudContainer`，不会访问本机地址。
- 本地后端只监听 `127.0.0.1:8787`，并使用独立 SQLite 文件 `backend/data/myroot-v070-devtools.sqlite`，不会向局域网开放，也不会读写 CloudBase 或生产 MySQL。
- 启动脚本会幂等写入带 `MYROOT_V070_LOCAL_DEVTOOLS` 标记的开发态评测定义，题目复用当前小程序中的健康起点 12 题和肠道健康 5 题；不会覆盖其他定义或本地用户记录。
- 开发态种子只有在显式开关、`NODE_ENV=development`、`127.0.0.1`、专用 SQLite 文件和本地 OpenID 登录同时成立时才启用，任一条件不符即拒绝启动。
- 本地联调不替代 UnionID、跨小程序会员数据、云端跨设备保存、模型供应商和真机验收。

## 启动

```bash
npm run dev:miniprogram --prefix backend
```

微信开发者工具私有配置 `miniprogram/project.private.config.json` 需要设置：

```json
{
  "setting": {
    "urlCheck": false
  }
}
```

该文件已被 Git 忽略且不会上传。仓库中的 `project.config.json` 仍保持 `urlCheck=true`。

停止服务时在运行该命令的终端按 `Ctrl-C`；服务会先停止接收请求，再关闭 SQLite。

## 本地测试身份

本地启动命令仅在非受保护运行时开放显式 OpenID 登录。可在开发者工具 Console 执行：

```js
wx.request({
  url: "http://127.0.0.1:8787/api/v1/auth/login",
  method: "POST",
  data: { openid: "myroot-local-devtools", appCode: "MYROOT" },
  success({ data }) {
    wx.setStorageSync("ROOT_TOKEN", data.data.token);
  },
});
```

此身份只存在于本地 SQLite；不得把本地 token、OpenID 或 SQLite 文件用于体验版和正式版。

## 健康建议

两项评测都完成后，`POST /api/v1/health/advice/generate` 会按正式 Interface 生成并保存建议快照。本地联调固定调用当前 CloudBase 环境已启用的 `hy3`，只发送两项评测的版本、结果代码、结果标题和安全分支标记，不发送原始答案、昵称、手机号、OpenID 或其他身份信息。

模型 API Key 只从 macOS 钥匙串的固定条目读取，不写入仓库、`.env`、SQLite、请求日志或启动命令。钥匙串不可用、模型超时、响应异常或内容校验不通过时，仍保存经审核的 `REVIEWED_FALLBACK`；命中安全停止分支时不调用模型。

钥匙串条目：

- service：`com.myroot.v070.cloudbase-ai`
- account：`myroot-v070-local-dev`

添加或更新时在 `backend` 目录运行：

```bash
swift scripts/store-local-health-advice-key.swift
```

该脚本关闭终端回显，通过 macOS Security Framework 保存完整长令牌，并在写入前校验令牌环境；密钥不会进入命令参数、Shell 历史或文件。用下列命令删除该条目即可撤销本地模型访问：

```bash
security delete-generic-password -a myroot-v070-local-dev -s com.myroot.v070.cloudbase-ai
```

生产、体验版和真机的凭据配置与供应商合规验收仍是独立发布门禁。
