# myRoot v0.5.4 发布说明

发布日期：待正式发布确认

## 本版范围

- 根项目、后端与小程序版本统一为 `0.5.4`。
- 微信私密接口统一接入平台隐私授权，覆盖手机号、头像昵称、选择打卡图片和保存分享图。
- 打卡图片改为小程序直接上传 CloudBase，仅向后端提交 `cloud://` 或受信任的 `https://` 引用；失败提交清理本次上传对象。
- 新增健康类敏感个人信息单独同意 Module，追加记录政策版本、同意或撤回、来源与时间。
- 未同意或已撤回时，服务端拒绝身体画像、健康问卷和打卡写入，但商品浏览与人工协助保持可用。
- 新增 MySQL 迁移 `003_privacy_consent.sql` 和对应关系投影。
- 生产环境矩阵新增隐私处理者名称、联系方式、保存天数与强制同意开关 Gate。
- 用户可在“我的 -> 隐私与身体记录授权”查看或撤回当前同意。
