# myRoot v0.8.0 Root 会员商城接入记录

日期：2026-08-31
基线：`6fbcc1cdb502`（v0.7.3 候选）
分支：`codex/myroot-v0.8.0-debt-cleanup-20260830`

## 结论

v0.8.0 已在本地代码中补齐 Root 会员商城只读接入：小程序商品页可展示服务端读取的有赞价格与 SKU 快照，“我的”页可展示订单和优惠券最小摘要，购买及订单/优惠券入口可跨小程序打开 Root 会员中心。接口不可用时仍展示官方基础商品和会员中心入口，但不再把基础快照误标为实时价格。

本记录只证明本地 Implementation 与自动化契约通过；不表示 CloudBase 已配置有赞凭据、已部署服务端、已上传体验版、已完成真机跳转或已发布生产版本。

## 商品实时价格

- 服务端通过 `youzan.item.detail.get/1.0.0` 按官方商品 ID 读取价格、图片、SKU 名称与库存状态。
- 有赞标题、营销文案、AppID 和商品跳转路径不进入动态覆盖面；这些字段继续由仓库中的官方商品白名单控制。
- 接口返回总级 `priceSync.status/reason/syncedAt` 和商品级 `priceLive/priceSource`，区分 `YOUZAN_LIVE`、持久快照和目录默认值。
- 服务端读取失败、店铺 kdt/grant id 缺失或返回商品不完整时，明确标记降级；小程序提示最终价格、库存与优惠以 Root 会员中心为准。
- 会员摘要与商品快照默认缓存 60 秒，用于限制第三方请求突发；缓存仅在服务端进程内存在。

## 订单与优惠券摘要

- 摘要接口必须登录，并且只接受通过服务端密钥 provenance 校验的微信 UnionID。
- UnionID 在服务端映射唯一有赞会员；零条或多条映射均失败关闭。
- 小程序只接收订单总数、待处理订单数、可用优惠券数、可准确计算时的七天内到期数量及同步时间。
- 订单号、金额、商品明细、手机号、地址、券码、有赞会员标识和原始响应均不会进入客户端响应或本地缓存。
- “我的”页沿用 0.7.0 已复核的两行布局，在原摘要位展示 `待处理/总订单` 和 `可用/近到期`，未改动受保护页面结构。

## 跨小程序跳转

- 已登录购买先调用 `POST /api/v1/products/jump`，由服务端返回官方跳转目标并写入最小跳转记录；网络或记录失败不阻断购买，回退到随包发布的官方目录目标。
- 未登录用户可直接使用随包官方目录跳转，不为记录跳转而强制登录。
- 商品跳转在调用微信 API 前校验 Root 会员中心 AppID、商品路径及允许的 query key；短链只接受客户端配置中的 Root 会员中心白名单值。
- 订单和优惠券入口沿用已配置的 Root 会员中心短链，保留登录后续跳、失败提示与重试。
- 商品和会员入口事件只记录商品/入口、结果、失败码、规范页面路径及目标来源，不记录身份或交易内容。

## 生产配置门禁

正式环境变量矩阵新增“Root 会员商城只读接入”组，至少要求：

- `ROOT_YOUZAN_ACCESS_TOKEN`：只存在服务端密钥配置中；
- `ROOT_YOUZAN_KDT_ID` 或 `YOUZAN_GRANT_ID`：ROOT 店铺的数值标识；
- 既有命令摘要密钥：用于校验可信 UnionID provenance。

可选配置包括第三方超时、会员摘要缓存和商品缓存 TTL。缺少 token 或店铺标识时，生产矩阵保持阻塞，运行时商品与会员摘要失败关闭并保留安全降级展示。
