2. 在取得明确授权和数据处理口径后，以手机号作为辅助匹配证据。
3. 为 `WEWORK_CONTACT_FIELD_MAP` 准备备注、来源活动、手机号和标签候选映射。

## 不能关闭生产 Gate 的原因

该导出不包含企业微信客户联系 Interface 使用的 `external_userid`，也没有可替代的稳定外部联系人 ID。

`添加人账号` 是企业内部成员账号，不能当作外部联系人 ID。客户名称、手机号或行号也不能生成一个伪造的 `external_userid`，否则标签写入、联系回写和幂等关联都会指向错误身份。

因此当前文件不能独立作为以下生产证明：

1. `WEWORK_CONTACT` 真实线索同步成功。
2. `WEWORK_TAG` 对真实外部联系人写入标签成功。
3. `WEWORK_CONTACT_WRITEBACK` 对真实外部联系人回写成功。
4. `ROOT_CUTOVER_WEWORK_FIELDS_CALIBRATED=VERIFIED`。
