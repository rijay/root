## 1. 范围声明

0.7.0 只以本文七项需求为范围来源。此前主 checkout 中未提交的方案及其 PRD 不进入本版本，不从 0.6.1 归档分支、归档标签或 `main` 回收实现。

线上 0.6.0 与微信审核中的 0.6.1 保持不变；0.7.0 在独立 worktree 开发、验证和留档。

## 2. 版本目标

1. 以黑、白、品牌橄榄绿和中性灰重建统一视觉体系，移除界面中的米色主基调。
2. myRoot 展示 Root 会员商城的订单、优惠券和实时商品价格摘要，并保留可靠的跨小程序跳转。
3. 优化首屏资料和图片加载，消除“我的”页已登录用户先显示未登录或核验中的明显闪烁。
4. 将健康问卷草稿、评测结果和回测记录保存到服务端，支持用户逐条删除。
5. 用户完成健康起点评测和肠道健康 5 道题自测后，展示由已审核规则确定的当前状态，并从经人工审核的建议池中匹配安全、稳定的健康建议。
6. 将 0.6.1 的“当前页面不可分享”修复正式纳入 0.7.0，保证公开页每次显示时恢复“转发给朋友”，同时避免分享敏感参数。
7. 将 ROOT PHGG 介绍改造成小程序原生科学档案页，提供公开阅读、目录定位、文献标识复制和当前页分享。

## 3. 产品与实现要求

### 3.1 全局配色

- 单一品牌色源：黑、白、品牌橄榄绿、中性灰；警告和风险色只用于对应语义。
- 页面和组件使用语义 token，不再直接写旧米色值。
- 不做不区分语义的全局颜色替换；按首页、商品、健康、活动、我的及次级页逐页验收。
- 图片素材中的自然色不属于代码配色门禁，但页面底色、文字、边框、按钮和渐变属于门禁范围。

验收：

- 旧米色调色板不再出现在 WXML/WXSS；新增自动检查阻止回归。
- 五个 Tab、登录注册、健康全流程、活动详情、内容详情和个人设置均无文字不可读、按钮失色、遮挡或布局漂移。
- 开发者工具与至少一台 iOS、一台 Android 真机完成逐页截图比对。

### 3.2 商城数据与跳转

- Root 会员商城是订单、优惠券和商品价格的权威来源；myRoot 只做只读聚合展示，不自行判定支付、核销、库存或售后最终状态。
- 账号优先使用同一微信开放平台下的可信 UnionID 关联；缺失或冲突时不得按昵称自动合并。
- “我的”页展示订单摘要、可用优惠券数量和更新时间；商品页展示服务端返回的价格及同步时间。
- 订单、优惠券和商品均可跳转到对应商城目标；跳转失败保留当前页面、可重试，返回 myRoot 后恢复原页面状态。
- 外部接口不可用时显示“暂未同步/以会员商城为准”，不得用本地静态值冒充实时数据。

验收：

- 同一测试会员在商城与 myRoot 的订单、可用券和商品价格一致。
- 无 UnionID、身份冲突、空数据、超时、令牌过期和跨小程序跳转失败均有可理解的降级状态。
- 完成脱敏只读探针、分页读取到结束、去重和读后校验；未读取真实数据前不得宣称已打通。

### 3.3 加载体验

- 登录资料采用“本地最小快照立即展示、后台刷新”的方式；退出登录或会话失效时同步清除快照。
- 已随包发布且不依赖用户状态的商品与评测目录直接作为稳定首帧，接口只在后台刷新价格、库存、评测进度和结果；不得先渲染整页 loading 再替换主页面。
- 健康状态、会员摘要等用户数据只使用当前登录会话的内存缓存，不写入公共页面缓存；退出登录立即清除。
- 页面请求去重、可取消，保留现有并发和超时预算；刷新失败时保留上次可用内容并明确提示。
- 非首屏图片懒加载，固定占位尺寸并处理加载失败；首屏关键图片保留优先加载。后台内容图片必须把授权素材宽高随接口返回，小程序在下载前按比例预留高度。
- 活动首屏加载占位与正式主卡使用相同高度；商品页、商品详情、健康页和“我的”页的主结构在后台刷新前后不得整体换版或改变主要区块位置。
- 记录页面可用内容时间、资料刷新耗时和图片失败率，不记录头像、健康答案、订单或优惠券内容。

验收：

- 已登录用户二次进入“我的”时首帧直接显示缓存资料，不先闪成“未登录”。
- 资料刷新失败时仍显示缓存资料并提示可重试；退出后不得残留上一位用户资料。
- 产品页和商品详情冷启动即显示随包商品快照；健康页冷启动即显示两项评测入口，后台结果返回后不替换整页。
- 非首屏图片启用懒加载，图片加载前后不造成主要布局跳动；内容长图在网络下载前已有与素材比例一致的占位高度。
- 开发者工具和真机分别用正常网络、弱网观察五个 Tab、商品详情、活动列表和内容长页，不能只用静态代码断言关闭本项。

### 3.4 健康数据服务端保存与删除

- `INITIAL` 与 `GUT_REGULARITY` 的草稿、答案、结果、问卷版本和回测记录统一由服务端保存。
- 只允许当前登录用户读写自己的记录；所有写入继续受健康敏感信息单独同意控制。
- 历史页和结果页支持逐条删除。删除一个评测记录时，其答案、结果、维度和以该记录为输入的健康建议一并删除或失效。
- 删除操作幂等；成功后立即从用户界面消失。必要安全审计只记录操作事实和记录 ID，不保存被删健康内容。
- 保存期限、到期脱敏、撤回同意和用户主动删除是不同机制，分别验证。

验收：

- 同一用户换设备登录后能读取服务端历史；不同用户不可互相读取。
- 草稿中断后可恢复；相同问卷 ID 与版本的两次结果可并列查看，仅在双方都有相同数值维度时展示数值变化，不为分类问卷虚构趋势分数。
- 用户删除后详情、历史和对比均不可再访问；重复删除不报未知结果。

### 3.5 当前状态与经审核健康建议

- 当前状态由版本化、已审核的问卷评分和安全规则确定，建议池不得改写评测分类或安全分流。
- 仅在两项评测均完成后匹配综合建议；运行时只使用完成匹配所需的最小结构化结果，不向外部模型服务发送用户健康数据。
- 建议池使用固定结构，经字段、长度、禁用表达、安全规则和人工审核后才能进入运行时版本。
- 命中风险分支时不进入普通建议匹配，只展示经专业审核的固定安全内容。
- 建议池缺失、版本不兼容或匹配失败时，自动降级到经审核的固定建议，不阻断评测结果。
- 用户界面统一展示“经审核健康建议”，不展示内容制作工具来源；内部保留建议池、内容、规则、审核人和审核时间版本，但普通日志不记录健康原文。

验收：

- 缺任一评测时明确提示还需完成哪一项；两项完成后展示两项当前状态和三条可执行建议。
- 风险样本不进入普通建议匹配；建议池故障时仍返回安全固定建议。
- 相同两次评测记录复用已匹配建议，不因反复打开页面产生漂移。
- 上线前完成建议池专业内容审核、隐私影响评估和运行时零外部模型调用验证。

### 3.6 公开页面分享

- 继承 0.6.1 的分享生命周期修复：公开页面在 `onShow` 时重新调用 `wx.showShareMenu`，避免从隐藏分享菜单的启动页返回后出现“当前页面不可分享”。
- 公开页面继续开放“转发给朋友”；PHGG 科学档案作为公开内容页，同时开放“分享到朋友圈”。其他页面不新增朋友圈分享，避免健康结果等非公开页面误开放。
- 公开页面分享回到当前公开页；只保留明确允许的查询参数，不携带令牌、签名、健康记录 ID、身份信息或其他私有参数。
- 敏感结果页或未列入公开白名单的页面即使触发分享，也统一安全回到首页。

验收：

- 分享菜单接口在公开页面返回成功；页面多次 `onShow`、从欢迎页进入和跨页面返回后仍可分享。
- 商品、内容、活动和 PHGG 科学档案分享卡片回到正确公开页面，且路径不含私有参数。
- PHGG 科学档案的“发送给朋友”和“分享到朋友圈”均可用；朋友圈打开仍回到当前档案页，且不携带来源参数或私有参数。
- 微信开发者工具验证不能替代 iOS 与 Android 真机的系统菜单分享和回流验收。

### 3.7 ROOT 核心原料 PHGG 科学参考文献集

- 使用小程序原生页面放入内容分包，不依赖 `web-view`、外部 H5 或新增业务域名。
- 产品 Tab 和“关于 Root”提供入口；在配料适用范围完成核验前，不把该档案绑定到任一单品详情，不默认两款 SKU 均适用。
- 页面正文严格以用户提供的 `ROOT_Phgg_Scientific_Reference.html` 为内容母版，母版 SHA-256 为 `33ad4be54acef24a7ac0d345ea7a1e54ae8ab3f8ab9ac34d8b4114c9f58d7081`。
- 小程序原生改造必须保留母版的封面说明、7 个章节、2 张对比/临床表、所有事实卡、15 条完整参考文献和原页脚，不擅自增删或改写正文。仅允许把 HTML/CSS 布局翻译为小程序 WXML/WXSS，并使用 0.7.0 黑白、橄榄绿和中性灰视觉 token。
- DOI、PMID、PMCID 支持一键复制；页面目录使用原生滚动定位；页面作为公开页支持当前页分享。
- 原稿等价呈现不等于内容已经获得发布批准。疾病、治疗、减重、强功效数字、消费者测试、认证和剂量等原稿内容仍需品牌、产品与合规逐项审核；未通过前不得上传候选版本或发布。

验收：

- 页面在 iOS 与 Android 常用尺寸下无文字遮挡、目录错位或安全区冲突。
- 页面章节、表格、事实卡、15 条文献及页脚与上述固定哈希母版逐项一致；文献标识复制内容与页面一致，分享路径固定回到科学档案页。
- 在单品详情增加入口前，必须补充当前包装配料或经批准资料，确认具体 SKU 与 PHGG/Fibalance® 的适用关系。

## 4. 发布门禁

本地代码和自动化检查通过不等于 0.7.0 可发布。以下证据分别关闭：

1. 有赞新密钥已轮换并进入受控密钥存储；只读 token、隐私字段返回形态和真实样本已验证。
2. 建议池全部内容完成专业审核并留存版本证据；正式运行环境不配置模型密钥、不调用外部模型服务，故障降级已验证。
3. 健康敏感信息说明已覆盖服务端保存、本地建议匹配、删除和保存期限，并完成隐私影响评估。
4. 微信体验版上传、两端真机视觉回归、商城跳转与返回、跨设备健康记录和删除均有独立验收记录。
5. 审核通过、生产发布和远端 Git 备份分别留证，不互相替代。
6. PHGG 科学档案内容完成品牌、产品与合规审核；具体 SKU 原料适用范围在增加单品入口前单独留证。
