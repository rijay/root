## 4. 公众平台填写文案

### 4.1 版本说明

> 新增产品聚合与会员商城跳转，支持健康起点评测回测、5题肠道自测及历史对比，完善活动浏览报名、页面分享和多机型导航适配。

### 4.2 审核备注

> 本版本为 ROOT 品牌会员服务小程序，提供产品信息展示并跳转至 ROOT 会员商城完成购买；提供非医疗诊断的健康状态自测、历史对比和一般生活方式建议；提供线下活动浏览与报名。健康问卷答案和评测结果仅保存在用户当前设备，使用前展示单独同意，用户可通过清理小程序数据删除。本小程序不提供疾病诊断、治疗或用药建议。

### 4.3 审核人员建议体验路径

1. 进入小程序，在 Launching 页点击“跳过”进入首页；
2. 点击底部“产品”，查看两款产品并使用购买入口跳转 ROOT 会员商城；
3. 点击底部“健康”，进入“肠道规律自测”，完成 5 道题并查看结果；
4. 在结果页点击“前往领取 5 支体验装”，跳转会员商城；
5. 点击底部“活动”，进入公开活动详情页查看活动信息。

公开浏览和自测无需提供独立测试账号。涉及微信头像昵称、手机号等能力时，按微信原生授权流程由审核人员自行授权。
