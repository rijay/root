# myRoot 0.7.0 健康建议隐私影响评估

## 1. 评估结论

0.7.0 采用“离线 AI 辅助起草 + 人工逐项审核 + 线上本地组合”的健康建议路径。当前草稿由 Codex 根据产品冻结的 6 类健康起点和 5 类肠道状态在仓库内生成，不调用 CloudBase 或 hy3，也不使用真实用户身份、答案、评测结果、健康状态或日志。

线上运行时只读取随候选工件发布的已审核建议池，按两个结果代码和评测记录 ID 稳定组合本地内容；不调用模型、不持有健康建议模型密钥、不向模型发送用户个人信息或健康信息。建议池未全部审核或校验失败时，运行时继续使用经审核固定建议。

当前综合判断：

- 用户健康数据的模型出网风险：在当前设计下不适用，前提是运行时零模型调用边界持续成立。
- 离线内容起草的数据风险：低；输入只允许产品状态枚举和固定内容规则，输出只进入待审核草稿。
- 健康数据主库、删除、备份、单独同意与真机验证：仍是独立发布门禁，未被本次建议池工作关闭。
- 建议内容安全：88 个新组件已起草但尚未人工审核，正式建议池仍为 `DRAFT`，运行时尚未接入。
- 历史 CloudBase 合成试验：不属于当前方案；已发生的合成请求继续按 7 天日志和既有证据管理，不包含用户数据。

## 2. 数据流

### 2.1 内容制作流

```text
冻结的产品分类与固定纤维规则
  -> Codex 离线起草 88 个通用组件
  -> 全部 PENDING_REVIEW 的 DRAFT 建议池
  -> 自动数量/唯一性/禁用表达/固定规则校验
  -> 产品、健康内容与合规人工审核
  -> 随候选工件发布的 APPROVED 建议池
```

内容起草只含结果代码、静态标签、结构约束和固定纤维文案，不读取用户数据库，也不接受用户请求对象。AI 不能直接把组件或建议池标记为 `APPROVED`。

### 2.2 用户运行流

```text
用户主动完成两项评测
  -> myRoot 服务端保存结果
  -> 安全停止分支优先判断
  -> 仅用结果代码和记录 ID 查本地审核建议池
  -> 固定纤维首条 + 起点行动 + 肠道行动
  -> 建议池无效则展示经审核固定建议
```

运行流没有模型服务、模型地址、模型 API Key、模型日志或模型缓存。

## 3. 建议规模与最小化

- 6 个健康起点组各含 6 条行动，共 36 条。
- 5 个肠道状态组各含 6 条行动，共 30 条。
- 另有 6 条回测提示、6 条起点摘要、5 条肠道摘要和 5 条肠道安全提醒。
- 新内容共 88 个审核组件；5 条固定膳食纤维规则逐字沿用 0.6.1。
- 30 个评测状态各形成 36 种行动组合，总计 1080 种；每次展示固定 3 条行动。
- 线上选择只需要两个结果代码和用于稳定选择的评测记录 ID，不需要原始答案、标题、问卷版本、身份标识或自由文本。

该规模在避免 30 份整段文案重复审核的同时，让每类状态有足够变化；新增审核仍集中在 88 个可复用、可追踪的最小组件。

## 5. 历史 CloudBase 事实与当前处理

2026-08-26 的账户核验确认 CloudBase 大模型日志可保存请求/响应且当前保留 7 天；Chat Completions 缓存不能由客户端控制。项目负责人另行确认输入、输出、日志和缓存不用于训练等二次用途，无其他受托方或跨境处理。

这些事实只用于管理已发生的合成试验和未来可能的供应商评估。当前建议池不需要 CloudBase、hy3 或模型钥匙串，因此：

- 不再继续外部生成请求，不产生新的 CloudBase 内容日志或费用。
- 不把 CloudBase 缓存 TTL 作为当前建议功能的个人信息保护措施。
- 历史试验不包含用户数据，仍按 7 天日志期限和既有证据归档。
- 未来如重启外部模型路径，必须先重新完成供应商、密钥、费用和数据边界评估。

## 7. 发布决策

### 可以继续

- 对 88 个新组件进行产品、健康内容与合规人工审核。
- 对 30 个状态预览固定纤维首条、摘要、安全提醒和多组稳定选择结果。
- 继续验证现有固定建议 fail-close 链路。

### 尚不可宣称完成

- “AI 辅助生成，经审核”的正式建议池：内容已起草，但尚未完成人工审核。
- 新建议池运行时接入：必须等审核通过后再实施。
- 0.7.0 候选、体验版或生产：仍需健康数据删除、备份、真机隐私流程、建议池工件和发布证据。

### 正式建议池放行条件

1. 88 个组件全部逐项审核并记录审核人和时间。
2. 五条固定纤维规则逐字一致，所有输出保持第一条。
3. 30 个状态的摘要、行动、安全提醒和稳定选择完成预览抽检。
4. 正式建议池文件与候选工件摘要一致。
5. 生产环境不存在健康建议模型地址或 API Key。
6. 候选环境证明运行时模型请求数为 0，建议池缺失时固定建议降级成立。
