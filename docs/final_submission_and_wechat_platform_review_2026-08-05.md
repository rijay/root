## 3. 当前正式功能范围

审核说明应只描述当前首发范围，不再介绍已退役的 7 日打卡、任务、奖励、Adapter 校准或旧 Admin 功能。

- 欢迎页：两屏沉浸式欢迎内容，可左右滑动或跳过。
- 首页：品牌与运营内容入口；没有已发布内容时显示“此刻内容正在准备中”。
- 健康：Root4U 健康起点评测、初始化建档、结果、非医疗性质的生活方式建议和后续评测推荐。
- 活动：线下活动浏览、报名和报名状态；没有已发布活动时显示正常空状态。
- 我的：会员资料、订单与优惠券入口、常见问题、客服、反馈、关于 Root、隐私与账号。
- Root 会员中心：用户主动点击“我的订单”或“优惠券”后，跳转至同主体的 `ROOT会员中心` 小程序；myRoot 不展示会员等级、积分、余额或资产摘要。

## 5. 审核备注草稿

> 1. 本小程序不提供医疗诊断、治疗方案或疾病疗效承诺。Root4U 用于整理用户主动填写的日常状态，并提供一般性生活方式建议；明显或持续不适会提示用户咨询专业医生或人工协助。
>
> 2. 核心审核路径：首次进入欢迎页 → 点击“跳过” → 进入“健康” → 点击“开始健康起点评测” → 使用微信手机号快捷登录 → 补充生日与性别 → 单独同意健康信息处理 → 完成 12 问 → 查看分类、三条生活方式提示和后续评测推荐。
>
> 3. 登录使用微信标准手机号授权，不设置独立账号密码；头像和昵称可拒绝授权，系统将使用 Root 默认头像和“Root用户”。
>
> 4. “我的订单”和“优惠券”会跳转至同主体 ROOT 会员中心小程序，myRoot 不复制展示会员资产。
>
> 5. 首页与活动内容由运营后台发布；当前没有已发布内容时展示明确空状态，不会长时间白屏或持续加载。

## 6. 审核员操作路径

### 6.1 无需登录即可检查

1. 打开小程序，左右滑动两张欢迎页。

3. 查看首页正常空状态。

3. 新用户填写生日和性别；头像、昵称可拒绝。
4. 阅读并单独同意“身体反馈与健康记录”处理说明。
5. 完成 12 问并提交。
6. 查看人群分类、安全分流结果、三条固定生活方式提示和推荐量表。

### 6.3 会员中心跳转

1. 进入“我的”。
2. 点击“我的订单”或“优惠券”。
3. 跳转至同主体 `ROOT会员中心` 小程序，正式短链为 `#小程序://ROOT会员中心/vTORPdF67tiEwCb`。
