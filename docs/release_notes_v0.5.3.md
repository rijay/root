# myRoot v0.5.3 发布说明

发布日期：待正式发布确认

## 本版范围

- 小程序、根项目和后端发布版本统一为 `0.5.3`。
- 小程序个人中心从统一版本配置读取展示值，不再保留硬编码版本号。
- 后端 `/health` 与 `/ready` 返回 `version` 和 `releaseId`，支持灰度版本归因。
- CloudBase 生命周期导出对象存储改用 Node SDK Adapter，并增加候选版专属上传/删除探针。
- 顶层验收增加生产依赖漏洞审计和候选 Store 就绪检查。
- 增加只读灰度验收脚本，必须显式开启才执行对象存储探针，脚本本身不调整流量。
- 定时 Job 支持新旧 token 双收和常量时间比较，可按无中断顺序轮换生产凭据。
- 有赞与企微 Adapter 增加官方响应结构、业务错误码和 token 获取处理。
- 运营预警 Webhook 支持企业微信机器人原生消息结构。
