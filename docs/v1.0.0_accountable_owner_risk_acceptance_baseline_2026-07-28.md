## 3. 风险接受范围

## 5. 证据强度与限制

该机制的分类为 `DIRECT_OWNER_DIRECTIVE_SELF_ATTESTED`，不是第三方审批、数字签名或六角色独立审查。Validator 能证明：

- 授权语句与冻结摘要完全一致；
- PRD、Design 与 Gate 决议 source binding 未漂移；
- D-001～D-010 与六类风险覆盖完整；
- V1 Contract 被保留且其摘要一致；
- 接受记录未被标记撤销；
- 运行、Candidate、部署和正式发布授权仍为 false。

Validator 不能证明责任人的法定身份、专业资质或外部组织授权。项目责任人已明确选择接受这一证据强度下降及相应责任集中。

## 6. 失效条件

以下任一情况使当前审批基线失效：

- PRD、Design 或 Gate 决议任一 source digest 改变；
- V2 Contract、授权语句、决定覆盖或风险覆盖被修改；
- V1 被取代 Contract 被删除或摘要漂移；
- `revocationStatus` 不再为 `ACTIVE`；
- Acceptance Envelope 摘要验证失败；
- 任一运行授权被改为 true。

失效后必须形成新 Contract 和新的明确责任人授权，不能编辑本记录冒充连续有效。
