# myRoot v0.5.8 发布说明

状态：已上传体验版；加载阻断已修复，但默认流量仍命中旧 `012`，健康同意 Interface 无法在该体验版完成验证

## 1. 本版目标

修复 `v0.5.7` 体验版中新用户登录后，健康信息单独同意跳转未完成时首页永久停留在“正在恢复你的身体记录”的 P0 阻断。

## 2. 代码变更

1. 首页先进入可恢复的健康信息单独同意状态，不再把未同意用户留在加载状态。
2. 首次进入时仍自动打开单独同意页；用户返回但未作选择时停留在明确的手动入口，不重复强制跳转。
3. 用户可重新打开说明，也可暂不同意并进入商品页；身体画像最终提交前仍执行同一同意 Gate。
4. 健康同意 Module 支持只检查状态而不触发页面跳转，其他调用方的默认行为保持不变。
5. 小程序静态校验新增登录后健康同意恢复路径检查，版本统一提升为 `0.5.8`。

## 3. 实际验证

1. `v0.5.8` 已于 2026-07-13 上传体验版；真机可从登录进入可恢复的单独同意入口，不再永久停留在“正在恢复你的身体记录”。
2. 点击“查看并确认”时返回“接口不存在”。只读探针确认体验版默认命中 `myroot-api-012`，该旧 Implementation 没有健康同意 Interface；定向 `myroot-api-024` 时同一路径存在。
3. 本版未修改 `myroot-api-012`、`myroot-api-024`、数据库、Cloud Function 或任何流量配置；该问题由 `v0.5.9` 定向预览继续验证。
