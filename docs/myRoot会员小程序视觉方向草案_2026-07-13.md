# myRoot 会员小程序视觉方向草案

日期：2026-07-13

性质：结构与气质预览，不替代现有 `design.md` 的生产品牌 Token

关联产品稿：`myRoot会员小程序产品定位与信息架构_v1_2026-07-13.md`

## Structured Brief

```text
[PLAN:@DESIGN|type=wechat_member_mini_program]
  |palette=light_clean|accent=muted_sage
  |typography=system_ui|display=same_as_body
  |layout=single_column
  |mood=editorial|density=spacious|section_gap=96px
  |hero=fullscreen_product_image+brand_statement+single_cta
  |sections=hero,member_next_step,product_philosophy,product_showcase,brand_support,tabbar
  |exclude=gradients,stock_photos
  |responsive=mobile_first
```

## Visual Theme & Atmosphere

- Mood: `editorial`
- Feel: 杂志式、克制、清楚、有品牌气质；品牌浏览场景可以沉浸，高频健康与任务场景保持低干扰。
- References: PANE 的全屏商品影像、一屏一个焦点和简洁商品内页。
- Product rule: 首页和新用户引导使用编辑感；首页不复制活动或任务列表；健康评测、活动报名、任务表单和“我的”不照搬大片排版。

## Color Palette & Roles

本草案按 `design-brief` 的封闭 Token 生成预览；进入实现前必须与 Root 现有 `design.md` 的暖白、墨黑、深橄榄、苔绿体系合并确认。

- Background: `#FFFFFF`
- Surface: `#F8FAFC`
- Text primary: `#0F172A`
- Text secondary: `#64748B`
- Accent: `#84A98C`
- Accent hover: `#6B8F73`

## Typography Rules

- Display: system-ui，600，`clamp(2rem, 5vw, 3.5rem)`
- Body: system-ui，400，`1rem/1.6`
- Mono: JetBrains Mono，400，`0.875rem`
- 中文优先使用系统字体，展示字体不牺牲健康信息和按钮可读性。
- 英文只用于小型系列名、产品注释和品牌层级，不与中文主任务争夺层级。

## Component Stylings

- Buttons: 中等圆角，Accent 背景，高对比文字；每屏只设置一个最高权重按钮。
- Cards: Surface 背景、1px 细边框、12px 圆角；不把所有内容默认装进卡片。
- Inputs: 透明背景、底部边框、清楚标签；健康表单保留说明与错误文本。
- Hero: 全屏真实产品/生活方式影像，底部渐变被排除，文字必须放置在可读的实色或经过验证的低干扰区域。
- Tab Bar: 五个带文字标签的入口；图标只辅助识别，不能替代文字。

## Layout Principles

- Max width: 移动端视口宽度；内容安全区内单列布局。
- Grid: `single_column`
- Section spacing: `96px`
- Content padding: `24px / 48px`
- 首页 Hero 可以满宽满高；后续内容回到统一内容边距。
- 健康、活动、任务和“我的”页面保持稳定标题、单列顺序和底部安全区。

## Depth & Elevation

- Shadows: 无装饰阴影；使用图片、留白、色面和细线建立层次。
- Borders: 1px solid，使用主文字约 8% 透明度的等效浅色。
- 悬浮主行动只用于确有持续提交需求的页面，并避开微信安全区域和底部 Tab Bar。

## Do's and Don'ts

- DO 使用一屏一个焦点。
- DO 将产品理念、健康解释、活动信息和任务状态分层。
- DO 确保文本达到 WCAG AA 对比度。
- DO 使用 Root 自有、已授权的产品和生活方式影像。
- DO 给五个 Tab 同时提供图标和文字。
- DON'T 添加调色板之外的颜色到本草案预览。
- DON'T 使用渐变制造可读性或科技感。
- DON'T 使用库存照片。
- DON'T 在评测和任务表单中使用全屏大片。
- DON'T 使用超过两套展示/正文字体。

## Responsive Behavior

- Breakpoints: 640px、768px、1024px、1280px；小程序首先按手机单列设计。
- Mobile: 所有内容纵向排列；Hero 满视口；五 Tab 固定底部。
- Tablet/Desktop preview: 内容保持居中，表单不无限拉宽；商品橱窗最多两列。
- Images: 流式宽度、保持比例、重要主体避开文字与微信胶囊区域。

## Agent Prompt Guide

- Do NOT invent colors outside this preview palette.
- Do NOT add box-shadows.
- Accent color appears maximum 3 times per viewport.
- All interactive elements need a visible focus state.
- Do NOT use gradients.
- Do NOT use stock photos.
- 首页可使用编辑式全屏影像；健康、活动、任务和“我的”优先任务清晰度。
- 生产实现前读取现有 `design.md`，由其品牌 Token 覆盖本草案的预览 Token。

## Dimensions resolved from defaults or existing constraints

- palette: `light_clean`；用户未指定具体色板，按 `mood=editorial` 的默认规则选择。
- accent: `muted_sage`；用户未指定强调色，选择最接近 Root 现有苔绿气质的封闭词汇值。
- typography: `system_ui`；用户未指定字体，按微信移动端可读性与现有 Root 约束选择。
- display: `same_as_body`；用户未指定展示字体，为避免 PANE 式英文排版损害中文可读性而选择。
- layout: `single_column`；由微信小程序和全屏首页结构确定。
- mood: `editorial`；由“参考 PANE 信息结构、全屏商品大片、简洁商品内页”推导。
- density: `spacious`；由全屏影像和品牌展示需求推导。
- exclude: `gradients, stock_photos`；沿用 Root 现有品牌与可读性约束。
